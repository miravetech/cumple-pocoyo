Cómo colocar las fotos

Abre Toolbox → DISTORTED HOTSPOT EDITOR → START. Arrastra una imagen para colocarla; usa SCALE para cambiar su tamaño. RX, RY y RZ ajustan su inclinación.

Al terminar pulsa Guardar posiciones. Sustituye el archivo tour.xml por el descargado. Los cambios no se escriben solos en la carpeta.

Al seleccionar o arrastrar una foto, las demás se ocultan temporalmente. Cambia de foto con el desplegable o pulsa «Mostrar todas las fotos» para ver el conjunto. El número de foto NO implica una asociación con el mismo número de vídeo.
